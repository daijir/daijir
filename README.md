## Featured Project: [Scripture Habit](https://scripture-habit.vercel.app)
A full-stack web and mobile application designed to help users build a consistent daily scripture study habit.

- **Features**: "3-day rule" streak tracker, study groups, and reflection sharing.
- **Platform**: Web and Android (Capacitor).
- **Backend & Security**: Firebase Auth, Firestore, and secure database rules.
